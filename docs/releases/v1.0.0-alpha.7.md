# WORZ 1.0.0-alpha.7

Обновлено: 2026-09-10 15:40:56 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-09-10 18:40:00 +03:00.

- Запуск теперь проходит в одном окне: плавно появляется окно, затем логотип, затем рабочий интерфейс. Отдельная маленькая заставка убрана.
- Последовательность сохраняется даже при быстрой загрузке; при более долгом запуске остаётся индикатор загрузки.
- Учтены системные настройки уменьшения анимаций. Подсказки не перекрывают заставку, кнопки управления окном остаются доступны.
