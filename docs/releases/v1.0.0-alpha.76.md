# WORZ 1.0.0-alpha.76

Обновлено 27.11.2026, 21:01 МСК. Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

- Рабочие области агента можно выделять протягиванием и удалять одним действием после подтверждения.
- В компактном режиме панель остаётся открытой при переходе указателя к кнопкам в заголовке.
- WORZ переносит существующие управляемые подключения на лёгкий нативный шлюз, если подпись шлюза, права и привязка клиента подтверждены.

### Видео

- В отдельном окне доступны FSR, Anime4K и AnimeVideo v3. Качество настраивается в меню «Качество → Обработка». Последний выбор сохраняется.
- Для AnimeVideo v3 можно выбрать стандартную обработку, быстрый режим со сглаживанием или TensorRT RTX FP16 на поддерживаемых NVIDIA RTX 30-й серии и новее.
- В отдельном окне Ctrl+R переподключает видеопоток. При смене качества окно восстанавливает вывод кадров в том же плеере.
- Встроенная кнопка со щитом управляет блокировкой рекламы для текущего сайта.

### Радио и интерфейс

- Радио доступно в нижней части боковой панели. Можно управлять громкостью, выбирать станции, добавлять избранное и создавать свои станции.
- Исправлено поведение выдвижной панели и полноэкранной кнопки встроенных видеоплееров.

### Подключение агентов

- Восстановление MCP после обновления Codex Desktop учитывает актуальное разрешение клиента. Сокращено число фоновых процессов Test MCP.

### Известное ограничение

TensorRT RTX проверен в реальном воспроизведении 480p. На 720p обработка может идти рывками. Плавность 720p зависит от видеокарты и её текущей нагрузки. В этом случае можно выбрать 480p в самом плеере или сменить режим обработки.

TensorRT RTX поставляется NVIDIA. [Лицензия NVIDIA TensorRT RTX](https://docs.nvidia.com/deeplearning/tensorrt-rtx/latest/reference/sla.html).
