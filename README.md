# WORZ

Обновлено: 2026-09-10 15:40:56 UTC.

**WORZ — Work Only Related Zones**: Windows-приложение для раздельных рабочих пространств, профилей и вкладок веб-сервисов. Каждый профиль использует собственную постоянную Electron Session; вкладки, split view, расширения, загрузки и RAM Saver управляются внутри одного desktop-клиента.

Текущая версия — **`1.0.0-alpha.7`**. Это публичная alpha для тестирования, а не стабильный выпуск. Обновлено: 2026-09-10 15:40:56 UTC.

## Возможности

- отдельные сервисы и профили без смешивания cookies и сессий;
- отдельные постоянные профили AI-агентов: полностью фоновый режим либо наблюдение через значок агента с безопасным временным входом пользователя;
- вкладки, история, split view и быстрые browser-команды;
- импорт/экспорт рабочего пространства и локальное восстановление предыдущего валидного состояния;
- управляемые расширения Chrome Web Store и распакованные расширения с проверкой доверия;
- Voice Over Translation для поддерживаемых видео;
- RAM Saver и защита выбранных вкладок от выгрузки;
- русский и английский интерфейс.

Команда не принимает произвольные URL или репозитории. Для автоматизации добавьте явный `-AcceptLicense`; режим `-Silent` требует этого флага. Подключение агента выполняется после установки параметром `-Connect codex|claude-code|generic-mcp|auto` и всегда требует подтверждения в WORZ.

Get-FileHash .\WORZ-1.0.0-alpha.7-windows-x64-setup.exe -Algorithm SHA256

4. Проверьте Authenticode. Официальный публичный release создаётся только для валидно подписанных файлов:

```powershell
Get-AuthenticodeSignature .\WORZ-1.0.0-alpha.7-windows-x64-setup.exe

Доверие сертификату не гарантирует отсутствие таких ограничений. Не отключайте системную защиту ради установки. Актуализировано: 2026-09-07 22:56:00 +03:00.

### Первое доверие нашему сертификату

Актуализировано: 2026-09-07 22:56:00 +03:00. Этот шаг изменяет доверие Windows для текущего пользователя и выполняется только по вашему решению. Скрипт установки не добавляет сертификаты автоматически.

1. Скачайте установщик с официальной страницы Releases и сверяйте SHA-256 по пункту 3 выше. До доверия его подпись может иметь статус `NotTrusted` или `UnknownError`; это ещё не разрешение запускать файл.
2. Откройте свойства установщика → «Цифровые подписи» → сведения о подписи → «Просмотр сертификата». Сверьте издателя и отпечаток с этой страницей, открытой непосредственно на GitHub: `49CA7AE2B77CCDAA1FC594DA8AD8D5691418F0AC`. Не доверяйте сертификату только на основании имени издателя.
3. Если вы доверяете этому издателю, выберите «Установить сертификат» → «Текущий пользователь» → «Поместить все сертификаты в следующее хранилище» → «Доверенные корневые центры сертификации». Подтвердите системный диалог. Устанавливается только публичная часть сертификата; закрытый ключ разработчика не распространяется.
4. Повторите `Get-AuthenticodeSignature` для установщика: теперь необходим `Valid` и тот же отпечаток. При несовпадении, истёкшем сертификате, повреждённой подписи или блокировке политикой установка прекращается. Затем запускайте установщик или проверяемую команду выше. `AllSigned` может отдельно запросить разрешение запуска подписанного скрипта.

Для отзыва доверия откройте `certmgr.msc` → «Доверенные корневые центры сертификации» → «Сертификаты» и удалите только сертификат с указанным отпечатком. После этого WORZ и его обновления могут перестать проходить проверку подписи. Наш сертификат действует до 31 августа 2029 года; текущие локальные сборки не имеют timestamp, поэтому после истечения срока понадобится новый выпуск с действующей подписью.

## Системные требования

- Windows 10/11 x64;
- доступ в интернет для подключаемых веб-сервисов;
- микрофон только для сценариев, которым он действительно нужен.

ARM64, macOS и Linux в этой alpha не поддерживаются.

## Известные ограничения

- автоматического обновления пока нет: новая alpha устанавливается вручную;
- работоспособность авторизации, сайтов и VOT зависит от внешних провайдеров и может меняться без обновления WORZ;
- данные сайтов, cookies и workspace сохраняются локально между запусками;
- камера, микрофон и уведомления выдаются сайту только после системного подтверждения пользователя; решение действует до закрытия WORZ и отзывается при сбросе Session;
- alpha может содержать ошибки интерфейса, совместимости и восстановления.
