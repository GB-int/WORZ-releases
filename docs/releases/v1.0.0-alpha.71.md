## Что изменилось

# WORZ 1.0.0-alpha.71

Обновлено: 2026-11-07 17:42 +03:00.

Исправлен запуск расширений после обновления: восстановленная Electron Session больше не использует service worker с прежним адресом скрипта. Неуспешный запуск корректно отзывает квитанцию подготовки; диагностика сохраняет только ограниченные данные собственного расширения.

Очистка касается только service worker проверенного расширения. Cookies, авторизации, настройки расширений, профили и вкладки сохраняются.

Проверено: 654 unit-файла, семь gates, миграция и повторный запуск persistent профиля в отдельных процессах, сохранность соседнего FAKE-хранилища, реальная блокировка контрольного рекламного запроса совместно с сетевыми ограничениями. В установленном Test прошли клик с проверкой эффекта, PNG 1440×900 и закрытие собственной сессии.

Личный сценарий InfoUrok после установки Main, фактическая реклама CVH и воспроизведение AGP пока не подтверждены. Эта версия не заявляет их полную приёмку.
