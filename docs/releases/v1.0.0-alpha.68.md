## Что изменилось

# WORZ 1.0.0-alpha.68

Обновлено: 2026-11-05 17:54 +03:00.

- В отдельном окне видео появились кнопки полноэкранного режима, восстановления размера и возврата во вкладку. Escape возвращает окно из полного экрана.
- Кнопка «Следующая серия» передаёт доступную команду исходному плееру. Окно остаётся открытым при смене серии; при недоступном или неоднозначном действии кнопка отключена.
- Исходная вкладка и воспроизведение сохраняются при переносе видео и возврате. Контекстное меню следует за текущим окном плеера. При возврате сохраняются исходное оформление страницы и изменения, сделанные самим сайтом во время просмотра.

Профили, авторизации и сохранённые вкладки не мигрируются.
