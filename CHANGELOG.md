# WORZ 1.0.0-alpha.45

Обновлено: 2026-10-11 23:48:00 +03:00.

Исправлена гонка холодного MCP-запуска: owner-registration публикуется после подтверждённого namespace и первого broker listener. Native client ждёт готовность owner pipe без открытия соединения, затем выполняет прежнее подключение и все проверки процессов, подписи и доступа.

Включены исправления предыдущего выпуска: startup_timeout_sec = 60 только для принадлежащего WORZ подключения Codex, до 16 соединений одного клиента в общем лимите 64.
