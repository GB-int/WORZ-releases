## Что изменилось

Обновлено: 2026-11-13 21:59 +03:00.

- Исправлено переподключение AI-агента после обновления, когда сохранённая привязка MCP переставала совпадать с действующей конфигурацией.
- Переподключение сохраняет прежнего клиента, профили и разрешения; посторонние или изменённые параметры по-прежнему отклоняются.
- Исправлен выбор проверенного MCP-хоста при подготовке конфигурации подключения. Основной и тестовый контуры сохраняют раздельные настройки.
