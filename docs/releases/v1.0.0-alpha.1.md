# WORZ 1.0.0-alpha.1

Обновлено: 2026-09-05 19:49:11 +03:00.

Первая публичная alpha WORZ предназначена для раннего тестирования на Windows 10/11 x64. Актуализировано: 2026-09-05 19:49:11 +03:00.

## Что проверить

- установка и первый запуск официального installer;
- моментальное стартовое окно, фоновая догрузка runtime и компактные кнопки свернуть/развернуть/закрыть;
- создание сервисов, профилей и вкладок;
- сохранение workspace после перезапуска;
- split view, история, загрузки и RAM Saver;
- авторизация на используемых вами сайтах;
- подключение AI-агента с отдельным профилем: `Абсолютно тихий` без видимых вкладок либо `Наблюдаемый` со значком, инспектором и безопасным временным входом пользователя;
- native-запросы microphone/camera/notifications: origin должен совпадать с текущим сайтом, а после restart/reset разрешение запрашивается снова;
- установка доверенного расширения и VOT на поддерживаемом видео.

## Ограничения

- это prerelease, возможны ошибки и несовместимости;
- автоматического обновления нет;
- сайты, авторизация, расширения и перевод зависят от внешних провайдеров;
- поддерживаются только Windows x64;
- данные сайтов и workspace сохраняются локально между запусками.
- фоновая работа AI-агента требует запущенного WORZ; на время пользовательского управления его текущая session завершается и затем создаётся заново.

## Рабочая область AI-агента

Актуализировано: 2026-09-02 18:30:45 +03:00.

Для каждого подключения создаётся отдельный постоянный AI-профиль с собственными cookies и авторизациями. В режиме `Абсолютно тихий` его вкладки не появляются в интерфейсе и не перехватывают экран, фокус или курсор; в режиме `Наблюдаемый` отдельный значок открывает текущие вкладки и ограниченную историю. История доступна после перезапуска, но не восстанавливает и не открывает старые вкладки автоматически.

История вкладок хранится локально до `30` дней: максимум `128` записей на профиль, `512` суммарно, `64` профилей и `512 KiB`. Из URL удаляются credentials, query и fragment, чувствительные сегменты pathname заменяются на `:redacted`; URL, e-mail, JWT, labeled secrets и OTP в title также маскируются. Содержимое страниц, cookies, формы и сетевые body не записываются.

`Войти / управлять` временно отключает агента от профиля и даёт пользователю обычный вход на сайт. Перед возвратом агенту WORZ переводит сеть в blackhole и закрывает соединения; при ошибке main recovery повторяет очистку и удерживает профиль закрытым. Page-owned native prompts/dialogs, HTML fullscreen, context menu и пользовательские download events для фонового AI-профиля отключены. Notifications, media и `clipboard-sanitized-write` разрешаются только во время явного пользовательского takeover; соответствующие agent-операции проходят через policy, capabilities и approvals.

После первой записи конфигурации v1 с рабочей областью не запускайте более старую alpha для перезаписи настроек. При несовместимости применяется forward-fix: установите текущую или более новую сборку; cookies и пользовательские профили при обновлении сохраняются.

## Проверка загрузки

Release содержит versioned installer, подписанный `install.ps1`, `SHA256SUMS.txt`, `release-manifest.json`, его detached-подпись `release-manifest.p7s`, очищенный CycloneDX SBOM, `WORZ Alpha Evaluation License 1.0` и THIRD_PARTY_NOTICES. Bootstrap, manifest, installer и установленный `WORZ.exe` привязаны к одному точному signer subject/thumbprint; скачиваемые LICENSE и installer проверяются по размеру и SHA-256 из подписанного manifest. Исходный код приложения, внутренний package и portable ZIP публично не распространяются. Не используйте артефакты обычного CI с пометкой `unsigned-ci`. Актуализировано: 2026-09-01 21:45:00 +03:00.

Текущая alpha бесплатна и разрешает личное некоммерческое ознакомление, тестирование и документированное agent API-управление официальной неизменённой сборкой. Распространение, перепродажа, сублицензирование и коммерческое использование не разрешены. Будущие выпуски могут перейти на подписку, платную модель или иные условия, но без ретроактивной платы или изменения условий уже полученной alpha-сборки. ## Граница публичного репозитория

Публичный `GB-int/WORZ-releases` должен начинаться как fresh/orphan-clean repository без истории файлов проекта. Workflow загружает полную историю (`fetch-depth: 0`) и останавливается, если в любом commit встречался путь вне фиксированного public allowlist. Исправление такой истории выполняется только явным пересозданием публичного репозитория; автоматическое разрушительное переписывание истории запрещено. Git хранит подписанный `install.ps1` без преобразования строк через `/install.ps1 -text`.

В публичную Git-историю допускаются только `17` файлов фиксированного allowlist: открытый подписанный bootstrap, правовые файлы, пользовательская документация и формы обратной связи. Installer, checksums, release manifest с detached-подписью и SBOM публикуются только как GitHub Release assets и никогда не commit-ятся в public Git tree. Актуализировано: 2026-09-02 01:18:00 +03:00.

Self-signed сертификат локальной разработки допускается только для внутренней candidate/acceptance-проверки на машине, где он явно добавлен в доверенные. Публичный workflow отклоняет self-signed сертификат и требует цепочку до доверенного CA; поэтому локальная подпись не выдаётся за доверенную подпись для clean VM. Актуализировано: 2026-09-01 21:45:00 +03:00.

Source-free package и обновление поверх прежней установки проверены 2026-09-02 01:05:00 +03:00: внутренний ASAR содержит только bundled runtime, frontend не содержит исходные module trees/source maps, а installer удаляет снятые с поставки файлы только из двух package-owned runtime-каталогов. Пользовательские профили и `%APPDATA%\WORZ` сохраняются.
