## Что изменилось

# WORZ 1.0.0-alpha.45

Обновлено: 2026-10-11 23:48:00 +03:00.

Исправлена гонка холодного MCP-запуска: owner-registration публикуется после подтверждённого namespace и первого broker listener. Native client ждёт готовность owner pipe без открытия соединения, затем выполняет прежнее подключение и все проверки процессов, подписи и доступа.

Ожидание готовности и подключение broker используют один монотонный бюджет 30 секунд; общий deadline native client остаётся 60 секунд. Self-connect namespace и physical owner-registration connect сохраняют прежний предел 5 секунд; owner response и authorization не изменены.

Включены исправления предыдущего выпуска: startup_timeout_sec = 60 только для принадлежащего WORZ подключения Codex, до 16 соединений одного клиента в общем лимите 64.

Проверка установленного выпуска требует двух холодных запусков с пятью настоящими Codex. Все пять соединений остаются открытыми; сессии общего рабочего профиля создаются и закрываются по очереди. Отдельная тестовая страница открывается, читается и закрывается через MCP с актуальным поколением pageRef.
