## [1.0.0-alpha.6] — 2026-09-08

Обновлено: 2026-09-08 20:54:57 UTC.

Обновлено: 2026-09-08 23:53:50 +03:00.

- Исправлено автоматическое закрытие WORZ перед обновлением: установщик запрашивает штатный выход и ждёт завершения приложения до замены файлов.
- Исправлен повторный запуск: уже открытое окно WORZ восстанавливается, в том числе при запуске из установщика.
- Уточнён запуск после установки и включён журнал установщика для диагностики.

## [1.0.0-alpha.5] — 2026-09-08

Обновлено: 2026-09-08 20:03:49 UTC.

Обновлено: 2026-09-08 23:02:31 +03:00.

- Исправлена «картинка в картинке» для встроенных видеоплееров: видео находится во вложенных iframe и открытом Shadow DOM без привязки к конкретным сайтам.

- Исправлено преждевременное закрытие окна PiP у плееров с атрибутом запрета этой функции.

## [1.0.0-alpha.3] — 2026-09-08

Актуализировано: 2026-09-08 19:30:00 +03:00.

### Добавлено

- Отдельный модуль обновлений: автоматическая проверка при запуске и каждые 30 минут, уведомления о новых версиях, скачивание и установка по кнопке в общих настройках.
- Критические обновления из подписанного релиза скачиваются и устанавливаются автоматически после штатного закрытия WORZ.
- Проверка подписи издателя и целостности обновления перед установкой; повреждённые и неподходящие релизы отклоняются.

### Исправлено

- Карточки подключения агентов показывают ожидание и результат даже после перерисовки настроек; подтверждение подключения открывается поверх WORZ.
- Исправлены сравнение отпечатка издателя и загрузка системных модулей в установочном скрипте Windows PowerShell.

Первая установка обновлятора при переходе с alpha.2 выполняется обычным установщиком. Alpha.3 — обычный, не критический выпуск.

## [1.0.0-alpha.2] — 2026-09-08

Актуализировано: 2026-09-08 13:14:00 +03:00.

### Исправлено

- Панель масштаба видна под страницей, нижний и правый отступы уменьшены.
- Новая вкладка сохраняет вставленный адрес при фоновых обновлениях; iframe Gmail не подменяет адрес основной страницы.
- Закрытие основного окна не обращается к уничтоженному webContents.
- Electron обновлён до 43.5.0 с исправлением падения сетевых запросов при работе расширений.
- Генерируемый integration kit сохраняет LF при checkout на Windows.

- Измерение private working set совместимо с Windows Server 2022 и остаётся привязанным к точному дереву процессов.
- Windows CI использует единый canonical temp root и не изменяет байты LF-файлов при checkout.

### Добавлено

- Восстановление вкладок через Ctrl+Shift+T, перетаскивание вкладок и кнопки управления масштабом.
- Управление отдельным окном видео и возвратом на страницу.

- Одна локальная команда проверяет конфигурацию, создаёт неизменяемый tag и публикует подписанный prerelease после зелёного CI.

## [1.0.0-alpha.1] — 2026-09-05

### Добавлено

- Windows x64 Electron-клиент с изолированными service/profile Session.
- Вкладки, история, split view, загрузки и рабочие пространства.
- Импорт/экспорт, резерв предыдущего валидного workspace и локальные snapshots.
- Управление расширениями, VOT, DevTools и browser capability tools.
- RAM Saver, pin/protection вкладок, русская и английская локализация.
- `Абсолютно тихий` и `Наблюдаемый` режимы AI-агента, отдельный постоянный профиль, пользовательский takeover, очищенная история и fail-closed recovery.
- Моментальное стартовое окно с фоновой инициализацией и компактная группа управления окном `72×28 px`.
- Публичные правила установки, приватности, безопасности и обратной связи.
- Проприетарная лицензия для личного некоммерческого использования официальных неизменённых сборок; изменения, распространение и коммерческое либо организационное использование требуют отдельного письменного соглашения. Добавлено: 2026-08-21 19:00:37 +03:00.
- Публичный GitHub prerelease с подписанным installer/bootstrap, checksum, manifest и очищенным CycloneDX SBOM. Актуализировано: 2026-09-05 19:49:11 +03:00.
- Fail-closed native consent для microphone, camera и notifications: решения изолированы по Session/origin/capability и отзываются при restart/reset.

### Ограничения

- Только Windows x64.
- Нет автоматического обновления.
- Поведение сторонних сайтов, авторизации и VOT зависит от внешних провайдеров.
