# WORZ 1.0.0-alpha.2

Обновлено: 2026-09-08 13:14:00 +03:00.

Публичная alpha WORZ для раннего тестирования на Windows 10/11 x64.

## Главное

Актуализировано: 2026-09-08 13:14:00 +03:00.

- компактная панель масштаба под страницей, с минимальными нижним и правым отступами;
- восстановление закрытой вкладки через Ctrl+Shift+T, перетаскивание вкладок и управление масштабом с клавиатуры;
- ввод и вставка адреса в новой вкладке сохраняются при фоновых обновлениях;
- служебный адрес карточки Google Contacts больше не подменяет адрес Gmail; ранее сохранённые адреса восстанавливаются;
- отдельное окно видео с изменением размера и возвратом на страницу;
- Electron 43.5.0 устраняет падение сетевых запросов при работе расширений, в том числе расширения перевода видео;
- исправлено обращение к уже закрытому окну при завершении приложения.


- моментальное стартовое окно с фоновой загрузкой приложения;
- компактные кнопки свернуть, развернуть и закрыть;
- отдельные профили и сессии, вкладки, split view, загрузки и RAM Saver;
- отдельная рабочая область AI-агента с тихим и наблюдаемым режимами;
- исправленное измерение private working set на Windows Server 2022;
- воспроизводимый Windows CI и однокомандный выпуск подписанного prerelease.

## Ограничения

- это prerelease, возможны ошибки и несовместимости;
- поддерживается только Windows x64;
- автоматического обновления нет;
- сайты, авторизация, расширения и перевод зависят от внешних провайдеров;
- данные сайтов и workspace сохраняются локально между запусками.

## Проверка загрузки

Актуализировано: 2026-09-07 22:56:00 +03:00. Эта альфа подписана собственным self-signed сертификатом независимого разработчика. На другом компьютере требуется явное доверие его публичной части по инструкции в [README](https://github.com/GB-int/WORZ-releases#readme). Отпечаток: `49CA7AE2B77CCDAA1FC594DA8AD8D5691418F0AC`. Возможны предупреждения SmartScreen и блокировка политикой Windows. Подписи без timestamp: после истечения сертификата 31 августа 2029 года понадобится новый выпуск. Скрипт не добавляет корни доверия автоматически.

Используйте только versioned installer из GitHub Release. Сверьте SHA-256 по `SHA256SUMS.txt` и убедитесь, что Authenticode-подпись installer и установленного `WORZ.exe` имеет статус `Valid`. Не используйте обычные CI-артефакты с пометкой `unsigned-ci`.
