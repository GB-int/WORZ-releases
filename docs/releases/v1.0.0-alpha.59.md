## Что изменилось

# WORZ 1.0.0-alpha.59

Обновлено: 2026-10-16 10:24 +03:00.

- Исправлено восстановление канала MCP после перезапуска WORZ: закрытое соединение больше не используется для новой команды, существующее разрешение сохраняется.
- Для одного conversationId повторные операции возвращают прежнюю рабочую ветку и браузерные профили; разные чаты получают отдельные ветки.
- Исправлены переходы между веткой, браузером и сервисом, возврат назад и переключение личной и агентской рабочих областей.
- Уточнены бюджеты ожидания и обработка тайм-аутов. Отправленные команды с неизвестным результатом автоматически не повторяются.
- Усилены проверка и перенос подписанного Test-кандидата в релизный контур.
- Исправлен сбор метрик Windows при завершении краткоживущего процесса: подтверждённо освобождённая память учитывается корректно, а ошибки измерения живых процессов продолжают блокировать проверку.

Проверенный Test-кандидат прошёл штатные проверки подписи и установки, 2559 автоматических тестов (0 ошибок, 1 пропуск), 39 условий живой проверки веток и вкладок и 30 условий изолированного интерфейсного стенда. После Main restart тот же MCP восстановил работу без повторного подключения. Нагрузочная проверка Electron прошла сценарии 1, 2 и 8 страниц с подтверждённой изоляцией процессов, освобождением измерений и очисткой временных ресурсов.

Публичная страница входа Twitch проверена через прямой MCP в Test: страница загрузилась, форма входа прочитана. Полный OAuth-переход Twitch пока не подтверждён; этот выпуск не объявляет сбой OAuth исправленным.
