# WORZ 1.0.0-alpha.57

Обновлено: 2026-10-13 18:59 Europe/Moscow.

Исправлена работа рабочих областей и подключённых агентов:

- Рабочая область агента использует общую боковую панель. Переключение между личными вкладками и областью агента сохраняет соответствующий интерфейс без наложения панелей.
- Ручное управление разблокирует страницу для пользователя и позволяет агенту продолжать работу в своей сессии.
- Подтверждённое подключение агента и выданные права сохраняются после обычного перезапуска WORZ.
- Устранён ложный отказ при навигации в документах со вложенными фреймами; проверки адресов и разрешённых источников сохранены.
- Исправлено подключение к разрешённым локальным страницам, когда DNS возвращает IPv6 раньше IPv4.

Перед выпуском проверены подключение после перезапуска, навигация агента при включённом и выключенном ручном управлении, переключение рабочих областей и загрузка локальной страницы и Twitch Developers. Настройки аккаунтов и OAuth не менялись.
