# WORZ 1.0.0-alpha.58

Обновлено: 2026-10-14 20:59:28 +03:00.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-14 20:56:53 +03:00.

- Подключение агента восстанавливается после перезапуска WORZ без повторного согласия. Временный ключ обновляется автоматически, а панель подключения показывает, что разрешение сохранено.
- Обновление Codex больше не сбрасывает согласие при смене версии, файла или сертификата. Проверяются доверенная подпись OpenAI, тот же точный издатель и согласованное расположение приложения; выданные права сохраняются до явного отключения.
- Исправлено восстановление сохранённой рабочей области после холодного старта WORZ. Пользовательские профили открываются в основном приложении; временный процесс MCP не создаёт отдельную копию личного окружения.
- Тайм-аут браузерной команды теперь учитывает ожидание подключения и восстановления связи. Агент получает различимые ошибки тайм-аута и отмены; уже отправленные команды автоматически не повторяются.
- Popup установленного расширения открывается, даже если расширение ещё не загружено в текущем профиле. Загрузка проходит штатные проверки, после открытия popup меню расширений закрывается. Улучшена диагностика расширений, агентских сессий и ошибок сохранения операций.

Перед выпуском проверены сохранение прав и работа обычного MCP-подключения после перезапуска, открытие AdGuard и блокировка одного рекламного запроса. Проверка этого запроса не подтверждает блокировку всех рекламных цепочек.
