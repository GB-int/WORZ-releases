# WORZ 1.0.0-alpha.43

Обновлено: 2026-10-11 22:31:32 +03:00.

Подключение Codex сохраняет достаточный таймаут запуска в управляемой конфигурации MCP. Изменение касается только записи WORZ и сохраняет более длинный пользовательский таймаут.

Брокер допускает несколько параллельных чатов одного клиента, сохраняя глобальный предел соединений и проверки подписанного процесса.

Проверка выпуска включает пять одновременно подключённых реальных процессов Codex с таймаутом из текущей конфигурации и операции создания, чтения и закрытия браузерной сессии.
