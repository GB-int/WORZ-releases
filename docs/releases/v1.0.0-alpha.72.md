# WORZ 1.0.0-alpha.72

Подготовлено: 2026-11-12 23:57:42 +03:00.

Исправлено перекрытие модальных окон, выдвижных панелей и меню нативной страницей браузера. Подключён проверенный Electron runtime с совместной обработкой DNR и MCP; доработаны подготовка личного профиля и управление нативными вкладками.

Проверено на WORZ Test: source fe9112ef91fb3be9c83b961c7e8334063365d18b, CandidateID bf11fc3c2317281c52b8835783a14353c9d023335422b42046394c20a8e3983e; 7 gates, 663 unit-файла, нативные сценарии и PNG собственной страницы.

По отдельному поручению пользователя выпуск выполняется до завершения оставшейся живой приёмки ограниченного MCP с AdGuard и полной матрицы плееров. Эти сценарии не объявляются подтверждёнными. Ошибка штатного ручного экспорта MCP (connector_identity_mismatch) исправляется отдельно и в этот snapshot не входит. Визуальная native-приёмка перекрытия дополнительно остаётся открытой; DOM-регрессия и открытие/закрытие каталога пройдены.

Профили, авторизации и данные сохраняются штатным обновлением.
