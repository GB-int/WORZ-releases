# Обратная связь и участие в WORZ

Обновлено: 2026-08-21 19:00:37 +03:00.

WORZ — проприетарный проект. Публичные изменения исходного кода, форки, патчи и
самостоятельные сборки не разрешены [лицензией](LICENSE).

## Как помочь проекту

- сообщить об ошибке через GitHub Issues;
- оставить отзыв о первой alpha через форму обратной связи;
- предложить улучшение без публикации исходного кода или конфиденциальных
  данных;
- сообщить об уязвимости только приватно по правилам [SECURITY.md](SECURITY.md).

Не прикладывайте пароли, cookies, токены, персональные данные, пользовательские
workspace-файлы или полные журналы авторизации.

## Изменения кода

Pull request с кодом принимается только по предварительному письменному
приглашению Правообладателя и на отдельно согласованных условиях. Незапрошенный
код может быть закрыт без рассмотрения. Сам факт отправки pull request не
предоставляет автору или третьим лицам права изменять, собирать, распространять
или коммерчески использовать WORZ. Актуализировано: 2026-08-21 19:00:37 +03:00.
