## Что изменилось

Обновлено: 2026-10-11 13:58:00 +03:00.

- Исправлен отказ `host_preset_credential_changed` при продлении Codex: runtime сохраняет согласованный набор разрешений из защищённого ключа.
- Переподключение включает MCP после подтверждения пользователя, сохраняя профиль и разрешения; при ошибке настройки откатываются.
- Проверки создания профилей без явного разрешения пользователя остаются обязательными.
