# WORZ 1.0.0-alpha.11

Обновлено: 2026-09-20 09:24:43 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-09-20 12:23:00 +03:00.

- Исправлена обработка мыши при переходе видео в полный экран: элементы управления у правого и нижнего краёв снова получают наведение и нажатия, в том числе во вложенных плеерах.
- Исправлен запуск установки обновления после завершения WORZ. Добавлена диагностика этапов передачи управления установщику.
- Исправлено подключение Antigravity при использовании конфигурации через символическую ссылку. Ошибки подключения теперь показываются с диагностическим кодом.
