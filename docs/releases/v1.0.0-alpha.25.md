# WORZ 1.0.0-alpha.25

Обновлено: 2026-10-06 23:07:32 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-07 02:04 +03:00.

- Озвучка видео запускается без перезагрузки текущей страницы. Рядом с кнопкой видны подготовка, ожидание запуска, подтверждённое включение и ошибка.
- Повторные нажатия не создают несколько запросов. Переход на другое видео или закрытие вкладки отменяет старую операцию и её статусы.
- Новые браузерные вкладки сразу показывают логотип WORZ и состояние подготовки браузера, загрузки сайта или ошибки. Индикатор работает отдельно в каждой панели разделённого просмотра.
- Исправлена упаковка служебного файла озвучки; его наличие и подключение проверяются в готовом пакете.
