## Что изменилось

# WORZ 1.0.0-alpha.44

Обновлено: 2026-10-11 23:18:00 +03:00.

Исправлено ожидание native MCP-канала при холодном запуске: клиент брокера ждёт до 30 секунд внутри общего лимита 60 секунд. Проверки процесса, подписи, владельца канала и предоставленного доступа сохранены; регистрация владельца и проверка namespace сохраняют прежний лимит 5 секунд.

Включены исправления alpha.43: сохранение startup_timeout_sec = 60 только для принадлежащего WORZ подключения Codex и поддержка до 16 одновременных подключений одного клиента в общем лимите 64.

Регрессия alpha.43 воспроизводилась на пяти настоящих Codex app-server: один клиент завершился с client_pipe_connect_failed до готовности канала. Результат не считается успешной проверкой.

Перед подтверждением установленного выпуска требуется холодный запуск с пятью Codex, создание сессий, получение списка страниц, закрытие сессий и подтверждение готовности штатных расширений установленного WORZ.
