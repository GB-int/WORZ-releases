## Что изменилось

# WORZ 1.0.0-alpha.66

Подготовлено: 2026-11-04 04:30 +03:00.

- Исправлено закрытие истёкших агентских сессий после переподключения. Проверяется актуальная привязка чата, ветки и профиля; доступ к страницам истёкшей сессии остаётся запрещённым.
- Ошибки выполнения отдельной команды возвращаются стандартным MCP-ответом и сохраняют работоспособность соединения. Ошибки транспорта и первоначальной авторизации остаются отдельными.
- Исправлено подтверждение завершения вспомогательного MCP-клиента, когда его потоки удерживаются после выхода собственного процесса. Проверки владения процессом и освобождения контекста сохранены.
- Диагностические результаты MCP сохраняются в корректном JSON, включая неуспешные вызовы. Неизвестные результаты изменяющих действий автоматически не повторяются.

Проверено: 2026-11-04 04:30 +03:00. Все 7 штатных gates, 643 unit-файла, 24 SDK-теста и живые проверки FAKE-контура: вкладки, ввод, viewport/fullpage PNG, история, heartbeat, сохранность исходных вкладок, истечение, переподключение и закрытие.

Ограничения актуальны на 2026-11-04 04:30 +03:00: совместная работа DNR расширений с ограниченным сетевым режимом MCP остаётся открытым вопросом. Полная совместимость произвольных Chrome-расширений не объявляется. Защита профилей и сетевые проверки не ослаблены.
