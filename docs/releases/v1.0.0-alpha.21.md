# WORZ 1.0.0-alpha.21

Обновлено: 2026-10-01 16:20:23 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-01 19:20:13 +03:00.

- Обновлён Electron и зависимости с известными уязвимостями.
- Локальные HTML открываются через ограниченный протокол; доступ к соседним файлам требует отдельного согласия. Сохранённые вкладки восстанавливаются с прежними адресами.
- Скачивания браузерных агентов изолированы по проверенному профилю; действия с чувствительными данными требуют подтверждения.
- Усилена проверка подписанного runtime и подключения агентов. Старое подключение необходимо один раз обновить кнопкой «Переподключить»; сохранённые разрешения и настройки профиля сохраняются.
- Исправлено заполнение SYGI после отмены операции, отключения интеграции или изменения страницы.
- Сохранены настройки, обновления, перевод страниц и управление окнами из предыдущей версии.
