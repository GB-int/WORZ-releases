# WORZ 1.0.0-alpha.8

Обновлено: 2026-09-13 11:43:03 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-09-13 14:25:00 +03:00.

- Исправлено завершение WORZ: ошибка очистки браузерного модуля больше не отменяет выход из приложения.
- Закрытие приложения завершает фоновые службы даже при сбое или зависании одного из компонентов.
- Установщик закрывает зависшие старые версии WORZ, включая процессы без видимого окна, и проверяет их завершение перед заменой файлов.
- Другая установка WORZ не затрагивается. Проверен запуск приложения после завершения установки.
