# WORZ 1.0.0-alpha.41

Обновлено: 2026-10-11 17:28:24 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-11 20:28:00 +03:00.

- После подтверждения регистрации владельца MCP клиент использует уже проверенную идентичность и удержанный handle процесса. Повторное обращение к закрываемому каналу регистрации удалено; проверки владельца и брокера сохранены.
- При завершении служебного клиента диагностический кадр дочитывается до закрытия stdout. До проверки процесса разрешён только фиксированный код ошибки; положительное сообщение не предоставляет доступ.
- Сохранены согласованные пределы ожидания проверки процесса и исправление проверки встроенных расширений.
