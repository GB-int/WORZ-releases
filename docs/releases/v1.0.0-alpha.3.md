# WORZ 1.0.0-alpha.3

Обновлено: 2026-09-08 19:30:00 +03:00.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

- В общих настройках появился модуль обновлений. WORZ автоматически проверяет новые версии при запуске и каждые 30 минут, показывает уведомление; скачивание и установка обычных обновлений выполняются по кнопке.
- Критические обновления могут устанавливаться автоматически. Приложение принимает такую отметку только из подписанного релиза, проверяет файлы и выполняет штатное закрытие перед установкой.
- При подключении Gemini Antigravity и других агентов отображаются ожидание и результат, которые сохраняются при обновлении настроек. Окно подтверждения привязано к WORZ.
- Исправлена проверка издателя в установочном скрипте и совместимость с Windows PowerShell.

## Установка

При переходе с alpha.2 установите alpha.3 обычным установщиком: в предыдущей версии ещё нет встроенного обновлятора. Рабочий профиль сохраняется. Эта версия выпущена как обычное обновление.

Встроенное обновление поддерживает штатную установку WORZ для текущего пользователя Windows x64. Доступны [инструкция по установке](https://github.com/GB-int/WORZ-releases#readme) и [подключение агентов](https://github.com/GB-int/WORZ-releases/blob/main/docs/AGENT_CONNECT.md).

Файлы подписаны локальным сертификатом WORZ; порядок проверки сертификата и SHA-256 приведён в инструкции. Это alpha-выпуск для раннего тестирования.
