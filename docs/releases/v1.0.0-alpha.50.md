# WORZ 1.0.0-alpha.50

Обновлено: 2026-10-12 15:34:54 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

- Рабочие пространства агентов встроены в основной интерфейс WORZ: именованные ветки задач, Google/Яндекс или оба браузера, сервисы и вкладки.
- DevTools работает для выбранной вкладки; история и журнал действий открываются по кнопке. Настройки браузеров сохраняются при переподключении.
- Открытые вкладки сохраняются между запусками с прежними идентификаторами и профилями.
- Исправлена ложная ошибка чтения истории на Windows: недоступный идентификатор устройства больше не считается заменой файла; проверка inode, размера, границ и запрет символических ссылок сохранены.
