# WORZ 1.0.0-alpha.48

Обновлено: 2026-10-12 09:12:56 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-12 12:15 Europe/Moscow.

Исправлена передача контекста вкладки и фрейма в AdGuard при работе встроенного браузера: штатные CSS-правила и локальные скрипты расширения снова получают проверенный контекст текущего документа.

Контракт совместимости обновлён до v2. Проверяется принадлежность документа и фрейма через нативный API; подпись пакета, изоляция расширений, CSP и пользовательские настройки сохраняются.

Проверены подписанные пакеты AdGuard 5.4, 5.5.2.3 и 5.5.2.76. На указанной странице jut-su.net со свежим пакетом подтверждены отсутствие рекламного ролика и воспроизведение серии длительностью 24 минуты.
