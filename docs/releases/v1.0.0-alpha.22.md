# WORZ 1.0.0-alpha.22

Обновлено: 2026-10-04 00:07 +03:00.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-04 00:07 +03:00.

- Сайты открываются после подготовки расширений без повторной загрузки первой вкладки профиля. Закрытая вкладка не возвращается после подготовки, а выбранный пользователем адрес сохраняется.
- Исправлены обработка Esc и отмена переходов видео в полный экран. Навигация рекламного iframe больше не отменяет подготовку fullscreen, поздние события отменённого перехода не разворачивают окно повторно.
- Electron обновлён до 43.7.7: исправлена ошибка движка при закрытии браузерной вкладки.
- Обновлены Electron и зависимости; усилены проверки подписанного runtime, подключения агентов и изоляция скачиваний по профилям. После обновления старое подключение агента требуется один раз обновить кнопкой «Переподключить».
- Локальные HTML открываются через ограниченный протокол; доступ к соседним файлам требует отдельного согласия. Исправлено автозаполнение SYGI после отмены операции, отключения интеграции или изменения страницы.
- Исправлено затянутое ожидание закрытия WORZ при обновлении: длительность обхода процессов теперь входит в общий лимит.
- Существующие профили, настройки, разрешения и каталоги данных сайтов сохраняются. Проверены обновление установленной версии, однократная загрузка и сохранение cookies/localStorage между запусками.

Редкое зависание настоящего Alloha на 1–2 минуты ещё требует подтверждения исправления при реальном просмотре; автоматические проверки переходов fullscreen прошли.
