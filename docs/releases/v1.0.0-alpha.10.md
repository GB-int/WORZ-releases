# WORZ 1.0.0-alpha.10

Обновлено: 2026-09-14 10:04:03 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-09-14 12:55:00 +03:00.

- В окне выбора браузера появился Microsoft Edge с подписью «Для входа в Google». Используйте его для авторизации Antigravity и других приложений, когда Google отклоняет встроенный браузер.
- Ссылка открывается во внешнем Edge с сохранением параметров авторизации и возврата в приложение. Предпочтительный профиль WORZ не изменяется, дополнительная вкладка внутри WORZ не создаётся.
- Если внешний браузер не удалось запустить, WORZ показывает ошибку и позволяет повторить выбор или отменить открытие.
