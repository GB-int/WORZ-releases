## Что изменилось

# WORZ 1.0.0-alpha.65

Обновлено: 2026-11-03 20:54 +03:00.

- Исправлены снимки страницы через MCP: обычный PNG и PNG всей страницы.
- Исправлен порядок отображения автоматически раскрывающейся контекстной панели поверх страницы.
- Восстановлен общий путь открытия popup и настроек расширений по manifest.
- Для проверенного AdGuard сохранена исходная CSP пакетного WebAssembly и исправлен холодный запуск встроенных фильтров.
- MCP-клиент штатно освобождает временный контекст перед закрытием соединения; неподтверждённая очистка больше не удерживает его собственные потоки.
- Исправлен поиск select и textarea по подписи: текст самого поля больше не считается частью label.

Проверено: все 7 gates, 643 unit-файла и изолированные native-проверки. В установленном Test подтверждены ввод, выбор по подписи, клавиша, click, открытие/активация/закрытие вкладки, оба PNG и goto/back/forward/reload. Список исходных FAKE-вкладок сохранён; управляющая сессия закрыта. Профили и данные сохраняются штатным установщиком.

Известные границы: полная совместимость со всеми Chrome-расширениями не заявляется. Совместная работа AdGuard DNR с защищённой сетевой политикой MCP ещё не завершена; профиль, origin, DNS, CSP и сетевые ограничения не ослабляются. Обычный режим AdGuard DNR и реальный popup подтверждены отдельной native-квитанцией.
