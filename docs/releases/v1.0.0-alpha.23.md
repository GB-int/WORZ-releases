# WORZ 1.0.0-alpha.23

Обновлено: 2026-10-06 17:30:12 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-06 20:17 +03:00.

- Добавлена общая поддержка усилителей звука на стандартном tabCapture. Проверена работа Sound Booster и Volume Master; управление открывается с панели для выбранной вкладки.
- Поддержаны современные и callback-варианты захвата звука. При навигации, закрытии вкладки или сбое плеера захват прекращается и восстанавливается прежнее состояние звука; после повторного открытия создаётся новый поток.
- Сохранены проверки подписанных пакетов и изоляция профилей, вкладок и расширений. Для расширений без захвата сохраняются нативные API вкладок и окон.
