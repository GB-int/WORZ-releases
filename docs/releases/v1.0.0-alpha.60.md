# WORZ 1.0.0-alpha.60

Обновлено: 2026-10-16 16:03 +03:00.

Исправлен завершающий шаг установки через `install.ps1`: после успешной установки WORZ сценарий больше не завершается ошибкой зарезервированной переменной PowerShell `$Host`.

Проверен режим без подключения агента и запуск выбранного подключения: поведенческий тест выполняет функции PowerShell с подменой запуска приложения и сохранения квитанции. Дополнительное подтверждение подключения не требуется, если установка запущена без выбора агента.

Обновлено: 2026-10-16 16:03 +03:00. Проверка изоляции установщика Test учитывает временно недоступный путь процесса WORZ: повторно запрашивает процессы до пяти секунд. Запущенный Test или постоянно неопределяемый процесс по-прежнему запрещает установку; процессы рабочей alpha не останавливаются. Пройдены 28 поведенческих проверок в Windows PowerShell и PowerShell 7.
