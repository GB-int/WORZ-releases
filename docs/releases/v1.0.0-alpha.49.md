# WORZ 1.0.0-alpha.49

Обновлено: 2026-10-12 13:38:29 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

- Рабочие пространства агентов встроены в основной интерфейс WORZ: список веток, браузеров, сервисов и вкладок использует общий вид приложения.
- Агент может работать в Google, Яндексе или обоих браузерах. Каждый чат создаёт именованную ветку с отдельными сервисами и профилями браузеров.
- DevTools открывается для выбранной вкладки; история и журнал действий доступны в отдельной панели по кнопке.
- Открытые вкладки рабочих пространств сохраняются между запусками. Переключение веток и переподключение MCP сохраняют выбранные настройки и существующие профили.
- Исправлена связь вкладок с сервисами в основном реестре браузера для корректного чтения списка через MCP.
