# Поддержка WORZ alpha

Обновлено: 2026-08-21 20:46:26 +03:00.

WORZ находится в alpha-стадии. Поддержка ведётся публично через GitHub Issues:

- [ошибка](https://github.com/GB-int/WORZ-releases/issues/new?template=bug_report.yml);
- [отзыв или предложение](https://github.com/GB-int/WORZ-releases/issues/new?template=alpha_feedback.yml).

Issues принимаются только в отдельном публичном `GB-int/WORZ-releases`; приватный source-репозиторий не используется как пользовательский канал. Актуализировано: 2026-08-21 20:46:26 +03:00.

Перед созданием issue проверьте существующие сообщения и укажите версию WORZ, Windows, вариант установки и точные шаги. Один issue должен описывать одну проблему.

Не публикуйте пароли, cookies, токены, email аккаунтов, полный профиль Electron или необработанный экспорт workspace. Для уязвимостей используйте только [приватный канал](SECURITY.md).

Поддержка стороннего сайта, его аккаунта, блокировки или тарифа остаётся у соответствующего провайдера. WORZ принимает отчёты, когда проблема связана с desktop host, изоляцией Session, навигацией, расширениями, хранением или UI приложения.
