## Что изменилось

# WORZ 1.0.0-alpha.63

Обновлено: 2026-10-27 01:20:32 +03:00.

- Добавлен выбор фреймов и контекстов выполнения JavaScript, включая основной контекст страницы.
- Добавлено управляемое открытие, проверка состояния и закрытие отдельного окна DevTools.
- В настройках подключения появились отдельные разрешения для этих функций с явным согласием пользователя; исправлена проверка выбранного клиента при экспорте подключения.
- Скриншоты MCP передаются стандартными блоками изображений, в том числе после завершения длительной задачи. Улучшена диагностика таймаутов подключения.

Работа с контекстами выполнения и DevTools требует соответствующих разрешений и ограниченного по времени режима admin-dev. Ссылки на контексты сбрасываются при навигации; ограничения CSP сохраняются.
