# WORZ 1.0.0-alpha.75

Обновлено: 2026-11-24 15:49:11 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

- WORZ распознаёт запущенный Codex Desktop из пакета Windows и проверяет его подпись при подключении.
- Подписанный MCP-адаптер Codex передаёт запросы общему брокеру WORZ. Профили и разрешения каждого клиента сохраняют свои границы.
- RAM Saver отсчитывает время простоя обеих панелей с момента их ухода в фон.
