# Подключение AI-агента к WORZ

Обновлено: 2026-09-04 09:49:04 +03:00 — пресет Gemini Antigravity проверен на установленной версии и совместим с его штатной ссылкой конфигурации.

WORZ alpha поддерживает два пути подключения: встроенный экран в приложении и открытие этого экрана после установки параметром `--agent-connect`. Для Codex, Claude Code и Gemini Antigravity ручные policy, origin, TTL и путь к EXE не нужны: WORZ сам находит host, создаёт локальное MCP-подключение и выдаёт полный набор браузерных инструментов.

## Путь 1: мастер WORZ

Откройте настройки подключения агента и выберите preset:

- `codex` — OpenAI Codex;
- `claude-code` — Claude Code;
- `antigravity` — Gemini Antigravity;
- `generic-mcp` — любой MCP-клиент с ручной настройкой.

Перед подключением задайте только среду:

- отдельный профиль агента или выбранный общий профиль;
- имя отдельного профиля;
- `Тихо` или `Наблюдать`;
- `FORCE`, если агент должен работать без запросов и уведомлений WORZ.

Нажмите `Подключить` на карточке Codex, Claude Code или Gemini Antigravity. В обычном режиме WORZ запрашивает подтверждение только перед опасным действием. В `FORCE` запросы и экранные уведомления WORZ отключены, но тихий журнал действий сохраняется. Существующая MCP-запись `worz-browser` не перезаписывается молча. Для Generic MCP остаётся ручная настройка в разделе `Расширенные настройки`.

Для Antigravity WORZ сам находит установленное приложение и меняет только запись `worz-browser` в `%USERPROFILE%\.gemini\antigravity\mcp_config.json`. Если Antigravity использует штатную системную ссылку на `%USERPROFILE%\.gemini\config\mcp_config.json`, WORZ безопасно изменяет конечный файл внутри `.gemini`, не заменяя ссылку. Ссылка за пределы `.gemini` блокируется. Остальные MCP-серверы и настройки сохраняются. Поскольку текущая Windows-сборка Antigravity не подписана Authenticode, запуск идёт через дополнительный подписанный WORZ-wrapper; общая проверка host-процессов не отключается. Готовая фраза для агента:

> Подключись к WORZ. Запусти установленный WORZ с параметрами --agent-connect auto (обычный путь: & "$env:LOCALAPPDATA\Programs\WORZ\WORZ.exe" --agent-connect auto). Я выберу среду и режим в WORZ, после чего проверь доступные MCP-инструменты. Если включён FORCE, не жди дополнительных подтверждений WORZ.

Если WORZ уже установлен в стандартную пользовательскую папку, агент может только открыть мастер этой командой:

```powershell
& "$env:LOCALAPPDATA\Programs\WORZ\WORZ.exe" --agent-connect auto
```

Команда не передаёт credential и только открывает экран подключения. Пользователь выбирает приложение, профиль, видимость и FORCE; технические права и локальную MCP-регистрацию создаёт WORZ. Отдельный постоянный профиль `agent-browser / agent-<id>` назначается автоматически, если пользователь не выбрал общий профиль. Актуализировано: 2026-09-02 23:10:12 +03:00.

## Путь 2: после установки

Однострочная установка из публичного репозитория описана в README. Для автоматизированного сценария после проверки и принятия лицензии используйте только фиксированный параметр:

```powershell
.\install.ps1 -AcceptLicense -Silent -Connect codex
```

Допустимые значения `-Connect`: `none`, `auto`, `codex`, `claude-code`, `antigravity`, `generic-mcp`. `auto` открывает выбор host в интерфейсе WORZ. После успешной установки WORZ запускается с командой `--agent-connect <host>`; FORCE включается только самим пользователем в WORZ.

## FORCE и ручной MCP

FORCE действует только внутри выбранной браузерной среды WORZ. Он не выдаёт агенту доступ ко всей Windows, не отключает проверку личности подключённого host и не смешивает cookies разных профилей. Отключаются именно approval-очередь и экранные уведомления WORZ; аудит, срок подключения и возможность немедленно отключить клиента остаются.

Не вставляйте в команды пароли, API-ключи, cookies, session-токены или содержимое секретных файлов. Для `generic-mcp` экспортируйте credential-free stdio-конфигурацию из WORZ, проверьте локальный transport и область разрешений, затем добавьте её в выбранный MCP-клиент. Не публикуйте экспорт в Issues или release assets.

Установка проверяет release-manifest, SHA-256 и Authenticode-подпись установщика. Если проверка не проходит или лицензия отклонена, приложение не устанавливается.
