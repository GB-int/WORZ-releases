# WORZ 1.0.0-alpha.47

Обновлено: 2026-10-11 21:57:46 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Панели обычных расширений открываются рядом с кнопкой внутри окна WORZ и работают с выбранной вкладкой. Исправлено определение активной вкладки в панели AdGuard. Устранена повторная проверка исходного пакета при открытии уже загруженного расширения; проверка целостности его рабочей копии сохранена.
