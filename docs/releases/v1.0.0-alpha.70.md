## Что изменилось

# WORZ 1.0.0-alpha.70

Подготовлено: 2026-11-07 13:10 +03:00. Source: 7359bf35c78af2db295c7081eaa0c9027607fb56. CandidateID: 115e288d79ce13e250584cd9229c3b78767bd782ff8ec5acda446b906be9b8e5.

- Исправлен нативный ввод агента в фоновые и уменьшенные личные вкладки: временная подготовка поверхности восстанавливается после команды.
- Добавлено восстановление активных фильтров AdGuard. Отдельное видеоокно сохраняется при рекламных вставках и замене исходного видео.
- Исправлено обслуживание Main-профиля, перенесённого через junction: native handles удерживают проверенные пути без миграции данных.
- Обновление завершает только подтверждённые MCP-хосты своего контура, включая прежние версии с проверенными protected receipts, подписью и полными hash.
- Фоновые MCP-хосты не создают renderer и отдельные GPU-процессы. Свежие SDK-подключения закрываются после работы и не загружают каталог плагинов Codex.
- Установщик доставляет проверку исторических квитанций как обязательный модуль подписанного inventory.

Проверено: 7 gates, 653 unit-файла, signed/native package, установленный Test, health, доверенный клик с изменением страницы, PNG 1440×900 и закрытие собственной сессии. Завершены 22 подтверждённых Test MCP-хоста; общий счёт WORZ снизился с 272 до 148, Test MCP в финальном замере отсутствует. Профили и авторизации сохраняются.

Ограничения: AGP не дошёл до воспроизведения в проверенном окружении; DNR с установленным prompt-MCP ещё не подтверждён. JS generation reload не заменяет native executable уже закешированного клиента Codex; штатный SDK recovery создаёт свежее подключение без ручного переключения.
