# WORZ 1.0.0-alpha.42

Обновлено: 2026-10-11 18:01:31 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-11 20:53:00 +03:00.

- Исправлен жизненный цикл владельца Windows named pipe: отдельный проверенный служебный процесс удерживает первую instance на весь срок поколения брокера. Завершение отдельного клиента больше не оставляет каналу PID завершённого процесса.
- Разрешение соединения требует одновременно живого владельца namespace и проверенного служебного процесса, который получил kernel PID текущего клиента. Неизвестные процессы и устаревшие поколения отклоняются.
- При закрытии сначала подтверждается завершение обработчиков соединений, затем владельца namespace. Публичный MCP-контракт, сохранённый профиль и разрешения доступа не меняются.
