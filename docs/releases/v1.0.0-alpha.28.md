# WORZ 1.0.0-alpha.28

Обновлено: 2026-10-10 10:04:01 UTC.

Публичная alpha WORZ для Windows 10/11 x64.

## Что изменилось

Обновлено: 2026-10-10 13:00 +03:00.

- Ускорен показ главного окна при запуске WORZ; проверка подписи и подготовка встроенной озвучки выполняются без задержки окна.
- Запуск с ярлыка во время завершения предыдущего сеанса сохраняется и выполняется после выхода приложения.
- В окне «Сохранить в SYGI» можно создать новый проект и сразу сохранить данные в него.
- Заставка загрузки появляется только при первом открытии страницы в новой вкладке и снимается при принятии документа, без ожидания долгих скриптов сайта.
- Навигация сохраняет адрес и историю одной операцией; устранены повторные обновления интерфейса.
- Исправлен конфликт подготовки VOT и AdGuard, вызывавший повторные перезапуски расширений.
- Уведомление о завершённой загрузке автоматически закрывается через 4,5 секунды; добавлена кнопка закрытия.

- Обычные установленные расширения открывают собственное окно или страницу настроек вместо менеджера WORZ, с изоляцией по выбранному браузеру и профилю.
