# История изменений WORZ

Обновлено: 2026-10-06 17:30:12 UTC.

Формат следует принципам Keep a Changelog, версии — Semantic Versioning.

## [1.0.0-alpha.23] — 2026-10-06

Обновлено: 2026-10-06 17:30:12 UTC.

Обновлено: 2026-10-06 20:17 +03:00.

- Добавлена общая поддержка усилителей звука на стандартном tabCapture. Проверена работа Sound Booster и Volume Master; управление открывается с панели для выбранной вкладки.
- Поддержаны современные и callback-варианты захвата звука. При навигации, закрытии вкладки или сбое плеера захват прекращается и восстанавливается прежнее состояние звука; после повторного открытия создаётся новый поток.
- Сохранены проверки подписанных пакетов и изоляция профилей, вкладок и расширений. Для расширений без захвата сохраняются нативные API вкладок и окон.

## [1.0.0-alpha.22] — 2026-10-02

Обновлено: 2026-10-04 00:07 +03:00.

- Убрана повторная загрузка сайта при первом открытии профиля: расширения подготавливаются перед первой навигацией.
- Поздняя подготовка расширений не возвращает закрытую вкладку и не заменяет адрес, уже выбранный пользователем.
- Идентификаторы профилей и расположение cookies, localStorage и IndexedDB сохраняются.
- Исправлены обработка Esc, отмена fullscreen при навигации iframe и поздние события отменённых переходов. Редкое зависание настоящего Alloha ещё требует подтверждения при реальном просмотре.
- Electron обновлён до 43.7.7: исправлена ошибка движка при закрытии браузерной вкладки.
- Публичный выпуск включает исправления безопасности и SYGI, внесённые в локальную alpha.21.
- Исправлено затянутое ожидание закрытия WORZ при обновлении: длительность обхода процессов теперь входит в общий лимит.

## [1.0.0-alpha.21] — 2026-10-01

Обновлено: 2026-10-01 16:20:23 UTC.

Обновлено: 2026-10-01 19:20:13 +03:00.

- Обновлён Electron и зависимости с известными уязвимостями.
- Локальные HTML открываются через ограниченный протокол; доступ к соседним файлам требует отдельного согласия. Сохранённые вкладки восстанавливаются с прежними адресами.
- Скачивания браузерных агентов изолированы по проверенному профилю; действия с чувствительными данными требуют подтверждения.
- Усилена проверка подписанного runtime и подключения агентов. Старое подключение необходимо один раз обновить кнопкой «Переподключить»; сохранённые разрешения и настройки профиля сохраняются.
- Исправлено заполнение SYGI после отмены операции, отключения интеграции или изменения страницы.
- Сохранены настройки, обновления, перевод страниц и управление окнами из предыдущей версии.

## [1.0.0-alpha.20] — 2026-09-28

Обновлено: 2026-09-28 20:32:56 UTC.

- Настройки всех восьми разделов используют общие карточки, поля, кнопки и интервалы. Улучшена компоновка в узком окне, оформление меню и редакторов профилей.
- Подключения Codex, Claude Code и Gemini Antigravity проверяются при запуске. Переподключение обновляет истёкший доступ и привязку к версии WORZ с сохранением профиля и его параметров. Настройки каждого агента открываются отдельно.
- Добавлена интеграция с SYGI: подключение приложения, выбор аккаунтов и полей для автозаполнения, поиск записей и сохранение новых данных сайта с подтверждением пользователя.
- Полоса вкладок прокручивается при переполнении; закреплённые вкладки остаются отдельно. Новые вкладки доступны без закрытия соседних, системный скроллбар скрыт.
- При восстановлении недавно закрытой вкладки в текущем запуске возвращается небольшой запас истории переходов, позволяющий воспользоваться кнопкой «Назад».
- В общей сборке сохранены перевод страниц и управление удержанием сервисов в памяти. Номер версии в настройках берётся из запущенного приложения.

Ограничение проверки: автоматические тесты и установка проверены; визуальная приёмка всех разделов настроек в реальном окне ещё не завершена.

## [1.0.0-alpha.11] — 2026-09-20

Обновлено: 2026-09-20 09:24:43 UTC.

Обновлено: 2026-09-20 12:23:00 +03:00.

- Исправлена обработка мыши при переходе видео в полный экран: элементы управления у правого и нижнего краёв снова получают наведение и нажатия, в том числе во вложенных плеерах.
- Исправлен запуск установки обновления после завершения WORZ. Добавлена диагностика этапов передачи управления установщику.
- Исправлено подключение Antigravity при использовании конфигурации через символическую ссылку. Ошибки подключения теперь показываются с диагностическим кодом.

## [1.0.0-alpha.10] — 2026-09-14

Обновлено: 2026-09-14 10:04:03 UTC.

Обновлено: 2026-09-14 12:55:00 +03:00.

- В окне выбора браузера появился Microsoft Edge с подписью «Для входа в Google». Используйте его для авторизации Antigravity и других приложений, когда Google отклоняет встроенный браузер.
- Ссылка открывается во внешнем Edge с сохранением параметров авторизации и возврата в приложение. Предпочтительный профиль WORZ не изменяется, дополнительная вкладка внутри WORZ не создаётся.
- Если внешний браузер не удалось запустить, WORZ показывает ошибку и позволяет повторить выбор или отменить открытие.

## [1.0.0-alpha.9] — 2026-09-14

Обновлено: 2026-09-14 09:02:32 UTC.

Обновлено: 2026-09-14 11:55:00 +03:00.

- При открытии внешней ссылки теперь можно выбрать Google или Яндекс и нужный профиль. Выбор доступен при запуске WORZ и в уже открытом приложении; отмена не создаёт вкладку.
- Восстановлено контекстное меню по правому клику: копирование, вставка, выделение, обновление страницы и навигация.
- При закрытии окно исчезает сразу, а WORZ завершает очистку и выгружает свои процессы в фоне.

## [1.0.0-alpha.8] — 2026-09-13

Обновлено: 2026-09-13 11:43:03 UTC.

Обновлено: 2026-09-13 14:25:00 +03:00.

- Исправлено завершение WORZ: ошибка очистки браузерного модуля больше не отменяет выход из приложения.
- Закрытие приложения завершает фоновые службы даже при сбое или зависании одного из компонентов.
- Установщик закрывает зависшие старые версии WORZ, включая процессы без видимого окна, и проверяет их завершение перед заменой файлов.
- Другая установка WORZ не затрагивается. Проверен запуск приложения после завершения установки.

## [1.0.0-alpha.7] — 2026-09-10

Обновлено: 2026-09-10 15:40:56 UTC.

Обновлено: 2026-09-10 18:40:00 +03:00.

- Запуск теперь проходит в одном окне: плавно появляется окно, затем логотип, затем рабочий интерфейс. Отдельная маленькая заставка убрана.

## [1.0.0-alpha.3] — 2026-09-08

Актуализировано: 2026-09-08 19:30:00 +03:00.

### Добавлено

- Отдельный модуль обновлений: автоматическая проверка при запуске и каждые 30 минут, уведомления о новых версиях, скачивание и установка по кнопке в общих настройках.
- Критические обновления из подписанного релиза скачиваются и устанавливаются автоматически после штатного закрытия WORZ.
- Проверка подписи издателя и целостности обновления перед установкой; повреждённые и неподходящие релизы отклоняются.

### Исправлено

- Карточки подключения агентов показывают ожидание и результат даже после перерисовки настроек; подтверждение подключения открывается поверх WORZ.
- Исправлены сравнение отпечатка издателя и загрузка системных модулей в установочном скрипте Windows PowerShell.

Первая установка обновлятора при переходе с alpha.2 выполняется обычным установщиком. Alpha.3 — обычный, не критический выпуск.

## [1.0.0-alpha.2] — 2026-09-08

Актуализировано: 2026-09-08 13:14:00 +03:00.

### Исправлено

- Панель масштаба видна под страницей, нижний и правый отступы уменьшены.
- Новая вкладка сохраняет вставленный адрес при фоновых обновлениях; iframe Gmail не подменяет адрес основной страницы.
- Закрытие основного окна не обращается к уничтоженному webContents.
- Electron обновлён до 43.5.0 с исправлением падения сетевых запросов при работе расширений.
- Генерируемый integration kit сохраняет LF при checkout на Windows.

- Измерение private working set совместимо с Windows Server 2022 и остаётся привязанным к точному дереву процессов.
- Windows CI использует единый canonical temp root и не изменяет байты LF-файлов при checkout.

### Добавлено

- Восстановление вкладок через Ctrl+Shift+T, перетаскивание вкладок и кнопки управления масштабом.
- Управление отдельным окном видео и возвратом на страницу.

- Одна локальная команда проверяет конфигурацию, создаёт неизменяемый tag и публикует подписанный prerelease после зелёного CI.

## [1.0.0-alpha.1] — 2026-09-05

### Добавлено

- Windows x64 Electron-клиент с изолированными service/profile Session.
- Вкладки, история, split view, загрузки и рабочие пространства.
- Импорт/экспорт, резерв предыдущего валидного workspace и локальные snapshots.
- Управление расширениями, VOT, DevTools и browser capability tools.
- RAM Saver, pin/protection вкладок, русская и английская локализация.
- `Абсолютно тихий` и `Наблюдаемый` режимы AI-агента, отдельный постоянный профиль, пользовательский takeover, очищенная история и fail-closed recovery.
- Моментальное стартовое окно с фоновой инициализацией и компактная группа управления окном `72×28 px`.
- Публичные правила установки, приватности, безопасности и обратной связи.
- Проприетарная лицензия для личного некоммерческого использования официальных неизменённых сборок; изменения, распространение и коммерческое либо организационное использование требуют отдельного письменного соглашения. Добавлено: 2026-08-21 19:00:37 +03:00.
- Публичный GitHub prerelease с подписанным installer/bootstrap, checksum, manifest и очищенным CycloneDX SBOM. Актуализировано: 2026-09-05 19:49:11 +03:00.
- Fail-closed native consent для microphone, camera и notifications: решения изолированы по Session/origin/capability и отзываются при restart/reset.

### Ограничения

- Только Windows x64.
- Нет автоматического обновления.
- Поведение сторонних сайтов, авторизации и VOT зависит от внешних провайдеров.
